# VS TEAMS 大会ビルダー

チーム対抗ボードゲーム大会（VS TEAMS フォーマット）の、設定・進行・集計・発表画面を1つにまとめたWebページです。
「設定」でチーム・人数・ROUND・卓・全員参加の種目・アイテムを決めると、その内容に合わせて得点の入力画面と発表画面ができあがります。

- `index.html` … ページ本体（`app.js` と一緒に置く）
- `sync/Code.gs` … 複数の端末で共有するときに使う、Googleスプレッドシート用の仕組み

## できること

| 画面 | 内容 |
|---|---|
| 設定 | 大会名、1チームの人数、チーム名と色、メンバー、アイテム、ROUND（卓の種類・人数・配点・ゲーム名）、全員参加の種目（点数の付け方・問題数） |
| 進行 | 卓ごとの順位・勝敗、種目ごとの結果を入れる。点数は自動で計算（同着は分け合い） |
| 集計 | 種目ごとの点数と合計、各チームのアイテム。発表画面を開く |
| 発表画面 | プロジェクター用。合計点、種目ごとの棒グラフ、アイテムの番号（中身は出さない）、タイマー |
| 卓配置 | ROUNDごとに、どの卓に誰が座るか |
| タイマー | ROUNDの分数をワンタッチでセット。残り15分・5分・時間切れで知らせる |
| データ・共有 | 複数端末での共有、結果だけを消す、設定の書き出し・読み込み |

「見本（八人の盤士杯）を読み込む」で、2026年10月の大会の設定を読み込めます。

### 卓の種類

- **個人戦**：順位に応じた点数がそのチームに入る。配点は自由に変えられる（6人卓は 7,5,4,3,2,1、4人卓は 10,7,4,1 が最初から入る）。
- **チーム戦**：勝ちチームに6点、引き分けは3点ずつ（変えられる）。
- **デュエル**：点数なし。勝ったチームがアイテムをもらう。

### 全員参加の種目の点数の付け方

- **人数×点**：渡せた人数・抜けた人数など。「○人以上でボーナス」も付けられる。
- **段階で点**：正しい位置の文字数など、値によって点が変わる（例：8:5,6:3,4:1）。
- **先着**：先にクリアしたチームだけ点が入る（一方を選ぶと、もう一方は自動で0点）。
- **点数を直接入力**：そのほか自由に。

## 公開のしかた（GitHub Pages）

1. GitHubのリポジトリの Settings → Pages を開く。
2. 「Deploy from a branch」で、このフォルダがあるブランチと `/ (root)` を選んで保存する。
3. 数分後、`https://<ユーザー名>.github.io/boardgame/builder/` で開ける。

データは開いた端末のブラウザに保存されます。アカウントは要りません。

## 複数の端末で共有する（スマホで入力して、パソコンで映す）

1. Googleスプレッドシートを新しく作る。
2. メニューの「拡張機能」→「Apps Script」を開き、最初からあるコードを消して `sync/Code.gs` の中身を貼り付けて保存する。
3. 右上の「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」を選ぶ。
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
4. 「デプロイ」を押し、表示された「ウェブアプリのURL」（`…/exec` で終わる）をコピーする。
5. 大会ビルダーの「データ・共有」でURLと大会ID（例：`bansishi-2026`）を入れて「共有を始める」を押す。
6. 表示された「ほかの端末で開くリンク」をスマホなどで開くと、同じ大会を見て入力できる。

- 3秒ごとに読み込むので、ほかの端末で入れた結果は数秒で反映されます。
- タイマーも共有されるので、どの端末からでも動かせます。
- 同じ欄を2台で同時に入れると、あとから保存した方が残ります。
- 「アクセスできるユーザー：全員」にすると、URLと大会IDを知っている人は誰でも読み書きできます。URLは参加者に配らないでください。
