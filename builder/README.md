# VS TEAMS 大会ビルダー

チーム対抗ボードゲーム大会（VS TEAMS フォーマット）の、設定・進行・集計・発表画面を1つにまとめたWebページです。
「設定」でチーム・人数・ROUND・卓・全員参加の種目・アイテムを決めると、その内容に合わせて得点の入力画面と発表画面ができあがります。

- `index.html` … ページ本体（`app.js` と一緒に置く）
- `sync/Code.gs` … 複数の端末で共有するときに使う、Googleスプレッドシート用の仕組み

## できること

| 画面 | 内容 |
|---|---|
| 当日 | 今のROUND・種目だけを表示。順位は1位の人から順にタップ（同着・1つ戻す・やり直す）。チーム戦・デュエルは勝ったチームのボタン、種目は数字のボタン。タイマーもここで動かす |
| 集計 | 種目ごとの点数と合計、各チームのアイテム。ここから発表画面を開く |
| 発表画面 | プロジェクター用。合計点、種目ごとの棒グラフ、アイテムの番号（中身は出さない）、タイマー |
| 準備 | 大会名、1チームの人数、チーム名と色、メンバー、アイテム、ROUND（卓の種類・人数・配点・ゲーム名・席の名前）、全員参加の種目（点数の付け方・問題数） |
| データ・共有 | 複数端末での共有、結果だけを消す、設定の書き出し・読み込み |

「準備」の「見本（八人の盤士杯）を読み込む」で、2026年10月の大会の設定を読み込めます。

- 欠席：個人戦の卓で「欠席がいる」を押してから欠席の人を押すと、その席は「下から2番目の順位にいた」ものとして数えます（その下の人は1つ下の順位）。1卓に1人まで。1対1の卓では使えません。
- アイテム：「集計」で、使ったアイテムに「使った」を押すと、発表画面でも使用済みとして薄く表示されます。
- 発表画面は Esc キーで閉じられます。開いているか・点数を伏せているかは、再読み込みしても残ります（別のタブや、あとで開き直したときは閉じた状態から始まります）。最後の種目まで入力が終わると「○○の優勝！」と出ます。
- 消す操作（白紙にする、見本を読み込む、ROUND・卓・種目・アイテムを消す、読み込み、結果を消す）は2回押しで実行されます。直後に画面下の「元に戻す」が出ます。
  - 消した卓・種目・アイテムは、その物だけが元の場所に戻ります（あとから入れた結果は消えません）。続けて押すと、さらに前に消した物も戻せます（10回分まで）。
  - 白紙にする・見本・読み込み・結果を消す、の「元に戻す」は、そのあとに何も入力していないときだけ使えます。
- 結果の入っている卓は、種類を変えたり、順位の付いた席がなくなるほど人数を減らしたりできません。先に「当日」でその卓の結果を消してください。

### 卓の種類

- **個人戦**：順位に応じた点数がそのチームに入る。配点は自由に変えられる（6人卓は 7,5,4,3,2,1、4人卓は 10,7,4,1 が最初から入る）。
- **チーム戦**：勝ちチームに6点、引き分けは3点ずつ（変えられる）。
- **デュエル**：点数なし。勝ったチームがアイテムをもらう。

### 全員参加の種目の点数の付け方

- **人数×点**：渡せた人数・抜けた人数など。「○人以上でボーナス」も付けられる。
- **段階で点**：正しい位置の文字数など、値によって点が変わる（例：8:5,6:3,4:1）。
- **先着**：先にクリアしたチームだけ点が入る（一方を選ぶと、もう一方は自動で0点）。
- **点数を直接入力**：そのほか自由に。

## 公開のしかた（GitHub Pages）

1. GitHubのリポジトリの Settings → Pages を開く。
2. 「Deploy from a branch」で、このフォルダがあるブランチと `/ (root)` を選んで保存する。
3. 数分後、`https://<ユーザー名>.github.io/boardgame/builder/` で開ける。

データは開いた端末のブラウザに保存されます。アカウントは要りません。

## 複数の端末で共有する（スマホで入力して、パソコンで映す）

1. Googleスプレッドシートを新しく作る。
2. メニューの「拡張機能」→「Apps Script」を開き、最初からあるコードを消して `sync/Code.gs` の中身を貼り付ける。
3. 貼り付けたコードの上の方にある `var WRITE_KEY = '';` の `''` の中に、自分で決めた合言葉を入れて保存する（例：`var WRITE_KEY = 'sakura-2026';`）。合言葉は運営スタッフだけに伝える。
4. 右上の「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」を選ぶ。
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
5. 「デプロイ」を押し、表示された「ウェブアプリのURL」（`…/exec` で終わる）をコピーする。
6. 大会ビルダーの「データ・共有」で、URL・大会ID（例：`bansishi-2026`）・合言葉を入れて「共有を始める」を押す。
7. 下に2つのリンクが出る。
   - **運営スタッフ用リンク**（合言葉入り）：入力するスマホで開く。参加者には渡さない。
   - **見るだけのリンク**（合言葉なし）：発表用のパソコンなど、入力しない端末で開く。
8. リンクを開くと「共有中の大会に参加しますか？」と出るので「参加する」を押す。

- 3秒ごとに読み込むので、ほかの端末で入れた結果は数秒で反映されます。タイマーも共有され、共有先の時計に合わせて動きます（端末の時計がずれていても同じ残り時間になります）。
- 結果は欄ごと（卓ごと・問題ごと）に、あとから入れた方が残ります。2台で別々の卓を同時に入れても消えません。同じ欄を2台で同時に入れたときだけ、あとから入れた方が残ります。
- 設定（チーム名・卓・種目など）は、まとめてあとから変えた方が残ります。設定を変えるのは1台だけにしてください。
- 共有に参加すると、その端末の内容は共有中の大会の内容に置きかわります。前の内容は控えとして残り、「データ・共有」の「共有に参加する前の内容を出す」で取り出せます。
- 同じブラウザで複数のタブを開いても、ほかのタブで入れた結果は自動で取り込まれます。
- `Code.gs` を新しくしたときは、Apps Script で「デプロイを管理」→ 編集 →「新バージョン」でデプロイし直してください。
- 合言葉を空のままにすると、URLと大会IDを知っている人は誰でも書き込めます。必ず合言葉を入れてください。
