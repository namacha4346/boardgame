第1条大会の形式

  1. 4人1組の4チーム、計16人で戦うチームリーグです。

  2. レギュラーシーズンの対局は、ボードゲームアリーナ（BGA）のターン制で行います。各自の空き時間に1手ずつ進めます。

  3. 毎節、4つの卓でそれぞれ別のゲームを遊びます。どの卓にも、4チームから1人ずつが座ります。

  4. レギュラーシーズンは4節です。そのあと全4チームが集まり、対面でファイナルを1日で行います。

第2条チームとエントリー

  1. チームは参加者どうしで自由に組みます。1チーム4人です。

  2. 全員、BGA のアカウントが必要です（無料で作れます）。

  3. LINE グループで、チーム名・メンバー4人・それぞれの BGA ユーザー名を送ってエントリーします。締切は 12月15日（火） です。

  4. 各チーム、1人以上は BGA のプレミアム会員（有料）に入ってください。プレミアム会員でないと卓を作れないゲームがあるためです。

  5. 補欠や代打は置きません。

第3条1節の進め方

  1. 1節は2週間（月曜に始まり、翌週の日曜に終わる）です。次の節の準備は、今の節の最後の週に進めます。

  2. 水曜（節の最後の週）次の節のゲーム提案 締切。4ゲームを公開
    土曜（節の最後の週）次の節のオーダー 締切（非公開で提出）
    月曜オーダー公開、節スタート
    日曜今の節の締切、着順を報告

  3. 節が始まったら、各卓でゲームを提案したチームの選手が BGA にターン制の卓を作り、残りの3人を招待します。プレミアム会員でないと卓を作れないゲームは、そのチームのプレミアム会員が作ります。

  4. 締切までに終わらなさそうな卓は、運営の判断で延長します。延長中の卓があっても、次の節は予定どおり始めます。

第4条ゲームの提案

  1. 各チームは毎節、ゲームを1つ提案します。提案したゲームの卓は、そのチームの「ホームゲーム」です。

  2. 提案できるのは、運営が用意したゲーム候補リスト（BGA で4人・ターン制で遊べるもの）の中のゲームです。重さや、プレミアム会員が必要かどうかの制限はありません。

  3. 一度使ったゲームは、あとの節では使えません（どのチームも）。

  4. 同じ節で提案がかぶった場合は、そのゲームを2卓で遊びます。

  5. ファイナルは対面で、実物のボードゲームを遊びます。ゲームの決め方と進め方は、会場に合わせて後日発表します。

第5条オーダー

  1. 毎節、チームの4人をどの卓（どのゲーム）に出すかを、チームで自由に決めます。全員が毎節どこか1つの卓に出ます。

  2. ゲーム提案とオーダーは、運営に LINE の個別メッセージで送ります。オーダーは締切まで他のチームには見えず、節の開始日に全チーム分をまとめて公開します。

第6条対局

  1. チーム内の相談は、対局中も含めて自由です。

  2. 持ち時間を過ぎた人がいても、BGA の機能で退出させることはしません。

  3. どうしても対局できない人は、その卓で 4位 とします。途中で抜けた場合も4位とし、残りの3人は最終的な順位で1〜3位とします。

第7条ポイントと順位

  1. 各卓の着順で、1位 +5、2位 +1、3位 −1、4位 −3 のポイントが入ります。

  2. 同着のときは、その着順のポイントを分け合います。例：1位が2人なら、(5＋1)÷2 で +3 ずつ。

  3. チームの順位は、メンバー全員のポイントの合計で決めます。合計が同じときは、1位を取った回数が多いチームを上とします。

  4. ファイナルには、レギュラーシーズンのポイントを半分にして持ち越します。ファイナル当日のポイントを足した合計で優勝を決めます。

  5. 個人の合計ポイントが一番多い人を MVP とします。

第9条結果と発表

  1. 対局が終わったら、各卓の誰か1人が、結果報告フォームで着順を報告してください。同着のときは、同じ欄に「A・B」のように名前を並べ、次の欄を空けます。

  2. 結果は結果発表ページに反映されます。順位・順位の推移・MVP・節ごとの結果を、誰でも見られます。

  3. 節ごとの結果は、発表スライドで LINE グループに共有し、SNS にも投稿します。

  4. レギュラーシーズンの対局の実況動画を作ります。BGA のリプレイを使い、できるだけ全卓を取り上げる予定です。

  5. SNS や動画には、表示名・チーム名・BGA の対局画面が出ます。載せてほしくない人は、エントリーのときに運営に伝えてください。

第10条賞品

  1. 優勝チームなどに賞品を用意します。内容は後日発表します。
