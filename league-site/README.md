# VS TEAMS LEAGUE 結果発表ページ

Board Game Arena で遊ぶチームリーグ「VS TEAMS LEAGUE」の順位と結果を表示するページです。

- `index.html`：ページ本体（順位、累計ポイントの推移、MVP、節ごとの結果、全画面の順位ボード）
- `config.js`：大会の設定（チーム、メンバー、日程、配点、結果のCSVのURL）

## 結果の入れ方

1. Google フォームの「結果報告フォーム」の回答先スプレッドシートを開く
2. ファイル → 共有 → ウェブに公開 → 回答のシートを「カンマ区切り形式（.csv）」で公開
3. 出てきた URL を `config.js` の `csvUrl` に入れ、`sample` を `false` にする

フォームの項目名は「節」「ゲーム名」「1位」「2位」「3位」「4位」「BGAの卓のURL」を含めてください。
同着は同じ欄に「A・B」のように名前を並べ、次の欄を空けます。

## 全画面の順位ボード

ページ上部の「全画面で順位を見る」から開きます。URL の最後に `#board` を付けると最初から表示されます。
